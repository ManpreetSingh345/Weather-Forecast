## ✨ Features

- 🌡️ **Real-Time Weather** — Temperature, humidity, wind, UV index, pressure & more
- 🔍 **Global City Search** — Search any city worldwide with live dropdown suggestions
- 📍 **Use My Location** — Auto-detects your location using browser Geolocation API
- 🔄 **Auto-Refresh** — Updates live data every 60 seconds with a pulsing indicator
- 📅 **7-Day Forecast** — Full week outlook with icons, min/max temps & rain probability
- 📊 **Analytics Charts** — Interactive Chart.js graphs for temperature, rain, wind & humidity
- 🎨 **Dynamic Ambient Glow** — Background glow changes color based on weather condition
- 🌓 **Dark / Light Theme** — Smooth toggle with localStorage persistence
- 📥 **CSV Export** — Download complete weather report with one click
- 💀 **Skeleton Loader** — Premium shimmer loading animation

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Structure & Semantics |
| CSS3 | Styling, Animations, Glassmorphism |
| JavaScript (ES6+) | Logic, API calls, State management |
| Chart.js 4.4 | Weather analytics charts |
| Open-Meteo API | Free weather data (no API key needed) |
| Nominatim | Reverse geocoding for geolocation |
